# ISN Projet 

## FoodTroc - *"No Waste, Just Taste"*


## Description
Besoin de tomates ? D'oeufs ? Ta salade va bientôt pourrir dans ton frigo ? Utilise **FoodTroc** !
Notre projet consiste à développer une application mobile/web écoresponsable, conçue pour optimiser la gestion de ton alimentation au quotidien. Avec FoodTroc, maitrise ton budget et lutte collaborativement contre le gaspillage alimentaire ! 
Voici les fonctionnalités principales :

Carte collaborative : publie ou récupére des aliments chez des utlisateurs de FoodTroc pour éviter qu'ils ne soient jetés.

Gestion d'inventaire : tes aliments sont suivis, (type, quantité, date de péremption), on t'alerte même quand tes aliments vont bientôt périmer !


## Comment l'utiliser ?

# Get started

- Installer VSCodium
- Installer l'outil git
- Selectionner le dossier de travail d'ISN
- Ouvrir le terminal dans ce dossier
- Utiliser git clone https://gitlab.insa-lyon.fr/cghosn/isn-projet.git afin de créer une copie de travail sur l'ordinateur
- Entrer login insa et mdp.
- Profiter de la copie locale pour développer !

# Comment ajouter des modifications

Ne jamais bosser sur le même fichier qu'un.e collègue !
Dans VS Codium, utiliser l'onglet source control pour créer/sélectionner votre branche de travail (pas le Main) !
Ajouter les fichier en lien avec votre modification et écrire un message expliquant la modification.
Push/Sync les modifications
